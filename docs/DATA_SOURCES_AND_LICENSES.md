## 3. How provenance was verified (reproducible)

1. Cloned the IslamicEval repository and OmarShafie/hadith at the commits above; downloaded the LFS object of `six_hadith_books.json` from the repository's LFS media endpoint.
2. `json.load` both Quran files and compared: **equal**. `json.load` both Hadith files and compared: **equal** (34,994 records). SHA-256 of the downloaded LFS object equals the `oid` in the pointer.
3. Parsed `nine_books_data.csv`, kept `BookID` ≤ 6 (34,994 rows), compared `hadithTxt` and `title` with `data/hadith.json`: **34,994 of 34,994 identical**.
4. Extracted `<ID>`/`<Response>` from `dev_SubtaskA/B/C.xml` and compared with the subset: **150 of 150 identical**.

## 4. What this means for the repository

* **Source code:** MIT (`LICENSE`), code only.
* **Quran text (`data/quran.json`):** unchanged Tanzil text, redistributed verbatim with the attribution above. **Do not edit this file**: Tanzil forbids changes. The application stores and searches the text unchanged. Corrections shown to users are copied from it; in the format of the official Subtask 1C
  gold corrections (`idgham.py`) assimilation marks (shadda) and ayah-number markers may be added to the *displayed* correction. The stored corpus itself is never altered; the team should decide whether this display convention is acceptable under Tanzil's no-change condition (it is applied only to the displayed correction, which follows the official Subtask 1C format).
* **Hadith texts (`data/hadith.json`):** redistributed unchanged as supplied by the IslamicEval organisers (Apache-2.0 repository), which in turn point to the GPL-3.0 KASHAF repository as their source. The KASHAF README states no separate licence for the texts, so **the exact terms for this digital compilation of the Hadith texts are not stated upstream**. Use here is non-commercial research for a hackathon, with full attribution; if you want certainty beyond that, ask the IslamicEval organisers (the task site lists contacts) to confirm in writing.
* **IslamicEval development data:** Apache-2.0 repository; reproduced with attribution and the citation above.
* **GPL note:** `data/hadith.json` is *data*, not linked code; the project's MIT code does not incorporate KASHAF code. The GPL-3.0 licence of the KASHAF repository is therefore documented but does not change the licence of Amanah AI's code.
